購入済みの素材をまとめる

購入履歴・自分のエクスポートをJSON/CSVで読み込みます。ページの表示だけで購入済みにはしません。Unityは既存のEditor連携も引き続き利用できます。

ダウンロード済みファイルを関連付ける

素材専用フォルダーを登録し、一覧の root_id / file に相対パスを指定できます。フォルダーの中身を勝手に走査・実行しません。



BOOTH・Fab・Humbleを全件同期
FAFNIRブラウザー拡張を開き、BOOTH・Fab・Humbleを全件同期を選択してください。各サイトに接続してログインすると、購入ライブラリのページ外・バンドル内素材もまとめて取り込みます。専用画面で一時停止・再開・定期更新を管理できます。
拡張機能は0.4.0へ再読み込みしてください。素材ファイルの一括ダウンロードは行いません。
