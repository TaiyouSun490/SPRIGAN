# Fafnir Owned Libraries & Asset Store RAG — 0.4.0

BOOTH・Fab・Humbleの購入ライブラリ全件同期と、Unity Asset Storeの商品候補・購入済みRAG登録を行うChrome/Edge拡張です。別製品のBOOTH用拡張とは異なる拡張ID・Native Messaging host `jp.game_stack_planner` を使います。

## 安全境界

- Unityの商品登録は、ボタンを押した現在タブだけを対象にします。既存のRAGへの追加情報は入力した呼び名・メモ・用途です。
- 全件同期は専用画面から明示的に開始します。BOOTH・Fab・Humbleの各サイトだけにオプションのhost permissionを要求し、公式ライブラリのタブ内で読み取り専用の取得を行います。
- Native Hostへ送信するのは、商品名・公開URL（ある場合）・提供元・安定した商品ID・種類・利用条件と、進捗・完了証跡です。取り込んだ素材はAsset Hub/MCPから検索できます。
- 注文キー・ダウンロードキー・Cookie・パスワード・API生レスポンスはFAFNIRへ送りません。アセット本体・画像・購入金額を一括取得しません。
- パスワードは公式サイトに入力します。Cookieを読み出すAPI、全サイト権限、ダウンロード権限は使いません。
- `scripting`は同一サイト内の購入ライブラリ解析、`storage`はチェックポイント、`alarms`はページ継続・定期同期に使います。
- 候補保存の状態は「購入未確認候補」のままです。
- 購入済みRAG登録は、商品ページ上で確認チェックを入れてボタンを押した場合だけ実行します。これは購入証明を検証した結果ではなく、ユーザーの自己申告です。
- 購入済みRAG登録には、用途・自分用の呼び名・メモのいずれか1つ以上が必須です。
- RAG登録しても、Unity Package Managerやローカルキャッシュに当該アセットが存在するとは限りません。ローカルでの利用可否は別途確認します。

## インストール

1. `pip install -e .` などで `fafnir-native-host.exe` を利用可能にします。旧名の
   `game-stack-native-host.exe` も互換aliasとして残ります。
2. Chromeの `chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」からこのフォルダーを選びます。
3. 表示された拡張IDを指定して、PowerShellで次を実行します。

```powershell
.\docs\install_game_stack_native_messaging_host.ps1 -ExtensionId <32文字の拡張ID>
```

4. Unity Asset Storeの商品ページを開き、拡張から用途を選んで候補保存します。
5. 購入済みRAGへ登録する場合は、必要に応じて自分用の呼び名を入力し、購入済みの自己申告チェックを入れて専用ボタンを押します。

既存インストールは拡張管理画面で**再読み込み**してください。新規のサイトアクセス権は、専用画面の「接続・ログイン」を初めて押したときだけ要求します。既存の拡張IDとNative Hostの組み合わせは維持できます。

## 3サイトをまとめて全件同期

1. 拡張ポップアップの **BOOTH・Fab・Humbleを全件同期**、または拡張の「オプション」を開きます。
2. 同期するサイトの **接続・ログイン** を押してアクセスを許可し、公式サイトでログインします。OAuthアプリ・APIキーの登録は不要です。
3. サイトを選択し、所有の確認にチェックを入れ、**選択したサイトをまとめて全件同期** を押します。
4. BOOTHの購入品・受取ギフト全ページ、Fabの取得済みライブラリ、Humbleの全注文のバンドル内商品を取り込みます。ページ外の商品やキー引換専用商品のメタデータも対象です。
5. 素材ファイルはダウンロードしません。**Asset Hubを開く**から取り込んだ素材を検索できます。ポートを変えている場合は詳細設定のURLを変更してください。

専用画面・ポップアップを閉じてもブラウザー起動中は続行します。通信断・ブラウザー再起動後は保存した進捗から再開し、Native Hostの応答喪失でも同じページを重複登録しません。ログイン待ち・仕様変更はサイト別に停止します。**一時停止／再開／最初から**で復帰できます。完了したサイトは今回だけ／6時間／1日／1週間の設定に従って更新します。一時停止した同期は定期更新でも勝手に再開しません。

全件走査の既定上限は1サイト10000ページで、詳細設定から変更できます。上限に達した場合は未完了で止めます。同期中は同じアカウントを使用してください。既存の利用条件確認・メモ・タグ・種類・ファイル関連付けは保持し、一覧にない既存素材は削除しません。購入やライセンスの独立した検証ではありません。

サイト内部の画面・API仕様に依存します。実アカウントの接続・全件走査は未検証です。詳細・内部データ形式・検証範囲は [Asset Hubドキュメント](../../docs/ASSET_HUB.md) を参照してください。

ローカルDBは既定で `%LOCALAPPDATA%\game-stack-planner\catalog.sqlite3` を使用します。
